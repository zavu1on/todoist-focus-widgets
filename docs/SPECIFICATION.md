# Техническое задание

> Это приложение не создано Doist, не связано с ним и не поддерживается им. "Todoist" является торговой маркой Doist Inc

**Focus Widgets** - это мобильное приложение, которое позволяет создавать яркие крупные виджеты, которые цепляют взгляд и помогают не забыть о задаче. Приложение заточено под платформу Android, светлую тему и интерфейс на английском языке. Вдохновлено [Duro: Habit Tracker for Elites](https://play.google.com/store/apps/details?id=com.duro.habits)


## Авторизация

Авторизация выполняется по личному **Токену доступа** (Access Token) Todoist, без OAuth-флоу.

### Обоснование

OAuth-флоу требует зарегистрированного приложения и обмена кода авторизации на токен с использованием `client_secret`, который в устанавливаемом на устройство пользователя приложении хранить негде — он перестает быть секретом. Извлечь готовый токен из redirect URL тоже невозможно: редирект возвращает одноразовый код авторизации, а не токен

При этом Todoist выдаёт пользователю бессрочный личный токен прямо в настройках, и он полностью покрывает сценарий персонального клиента. Поэтому приложение использует именно его

### Экран авторизации

Экран авторизации представляет собой форму единственным полем ввода API токена, а также пошаговую инструкцию получения токена: *Todoist → аватар в левом верхнем углу → Settings → Integrations → Developer → Copy API token*

При отправке формы приложение проверяет токен запросом данных пользователя, в случае успеха, токен сохраняется в `SecureStore`

### Сессия

При старте приложение читает сохранённый токен и проверяет его запросом данных пользователя. При успехе открывается экран со списком виджетов, при ошибке аутентификации - экран входа с сообщением "Срок действия токена истёк или он был отозван. Введите новый токен"

Если ошибка аутентификации приходит в ответ на любой запрос во время работы, приложение прекращает фоновые запросы, очищает кэш данных и возвращает пользователя на экран входа с тем же сообщением

**Выход** из аккаунта запись с токеном в `SecureStore`, очищает кэш данных и открывает экран входа. Действие требует подтверждения в диалоге, поскольку токен придётся вводить заново


## Страница списка виджетов

После успешной аутентификации, пользователю открывается экран со списком всех виджетов. Отображается preview самого виджета, его название, query-запрос, по которому фильтруются задачи, попадающие в виджет, а также кнопка добавления виджета на экран

Справа внизу расположена `FloatingActionButton`, которая позволяет создать новый виджет. При нажатии на виджет открывается форма редактирования виджета с возможностью удаления. При долгом нажатии на виджет - подтверждение на удаление виджета


## Виды виджетов

Необходимо реализовать два вида виджета:

1. **Pin** - виджет, который показывает *первую задачу* из удовлетворяющих фильтру, а также текст *+ N еще*, если задач несколько. Примитив для отображения на экране Android - <u>FlexWidget</u>
2. **List** - виджет, который показывает список удовлетворяющих фильтру задач. Примитив для отображения на экране Android - <u>ListWidget</u>

Если фильтр задач возвращает пустой список, то виджет показывает сообщение-заглушку о том, что текущих задач пока нет

При нажатии на виджет происходит редирект на задачу в приложение Todoist через deeplink ссылку вида `todoist://...`

### Хранение конфигурации фильтров

Конфигурация фильтров для виджетов: <u>название</u>, <u>query-строка</u>, <u>тип</u> хранится в локальной SQLite базе данных


## Действия с виджетами

### Создание/редактирование

Создание/редактирование виджета происходит через форму двухкомпонентную форму: конфигурации query-строки и название виджета

При конфигурации query-строки можно задать поля задачи, которые доступны в community версии Todoist: <u>проект(ы)</u>, <u>приоритет(ы)</u>, <u>дату выполнения</u>, <u>лейбл(ы)</u>. Также можно выбрать конкатенатор между условиями по полям - логическое И / логическое ИЛИ

При создании нового виджета есть два варианта отправки формы:

1. При долгом нажатии на кнопку отправки формы, конфигурация виджета сохраняется в БД, после чего появляется возможность разместить его на экране Android
2. При обычном нажатии, происходит только сохранение конфигурации в БД

### Удаление виджета

При удалении виджета, он удаляется как из БД, так и из экрана Android. Инициировать удаление можно как из экрана Android, так и из приложения 


## Обновление данных виджетов

Данные в виджетах обновляются при следующих событиях:

1. При успешном входе в приложение
2. При нажатии на виджет, до редиректа в Todoist
3. Раз в 30 минут, с использованием `android:updatePeriodMillis`

При ошибке сети / ошибке авторизации отображается соответствующая ошибка
